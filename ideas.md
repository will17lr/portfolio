# Idées de Design pour le Portfolio - Développeur Web Junior

## Approche Sélectionnée : Modern Minimal avec Accent Technique

### Design Movement

**Modernisme Minimaliste Technologique** - Inspiré par les portfolios de développeurs contemporains (Stripe, Vercel, GitHub), combinant la clarté du minimalisme avec une touche de sophistication technique.

### Core Principles

1. **Clarté Hiérarchique** : Navigation intuitive, sections bien délimitées, appels à l'action évidents
2. **Élégance Épurée** : Moins c'est plus - espaces blancs généreux, typographie soignée, pas de décoration superflue
3. **Accessibilité Technique** : Mettre en avant les compétences avec des visuels techniques (code snippets, icônes de tech stack)
4. **Fluidité Interactive** : Transitions douces, hover effects subtils, animations qui guident sans distraire

### Color Philosophy

- **Palette Primaire** : Bleu profond (#1e3a8a) + Blanc pur (#ffffff) + Gris neutre (#f3f4f6)
- **Accent Technique** : Orange/Amber (#f97316) pour les éléments interactifs et les highlights
- **Raisonnement** : Le bleu inspire confiance et professionnalisme, l'orange crée de l'énergie sans être agressif
- **Intent Émotionnel** : Compétence, fiabilité, modernité, accessibilité

### Layout Paradigm

- **Hero Section Asymétrique** : Texte à gauche, illustration/gradient technique à droite
- **Sections en Colonnes** : Alternance gauche-droite pour les projets (texte + image)
- **Grid Flexible** : 2-3 colonnes pour les compétences/technologies, responsive en mobile
- **Footer Minimaliste** : Liens sociaux + CTA, pas de contenu superflu

### Signature Elements

1. **Gradient Technique** : Dégradé bleu-to-purple subtil en arrière-plan des sections clés
2. **Icônes Technologiques** : React, TypeScript, JavaScript, SQL - affichées avec cohérence visuelle
3. **Code Blocks Stylisés** : Snippets de code avec syntax highlighting pour montrer l'expertise

### Interaction Philosophy

- **Hover States** : Cartes de projet qui s'élèvent légèrement avec ombre
- **Scroll Animations** : Fade-in progressif des sections en scrollant
- **CTA Buttons** : Boutons avec underline animation au hover
- **Smooth Transitions** : Toutes les interactions ont des transitions de 200-300ms

### Animation

- **Entrance** : Fade + slide-up léger (300ms) pour les sections au scroll
- **Hover** : Élévation de 4px avec ombre augmentée sur les cartes
- **Micro-interactions** : Underline animation sur les liens, scale subtil sur les icônes
- **Pas d'Excès** : Animations fonctionnelles, jamais décoratives

### Typography System

- **Display Font** : Geist (sans-serif moderne, utilisé par Vercel/Stripe) pour les titres
- **Body Font** : Inter (lisible, professionnel) pour le contenu
- **Hierarchy** :
  - H1 : 48px, bold, bleu foncé
  - H2 : 32px, semi-bold, bleu foncé
  - Body : 16px, regular, gris foncé
  - Small : 14px, regular, gris moyen
